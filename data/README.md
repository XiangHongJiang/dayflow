# 常用内容默认数据配置

本目录下的 `quick-defaults.json` 是 DayFlow「常用内容」默认清单的**唯一数据来源**。
直接用任意文本编辑器打开修改、保存、刷新页面即可生效，**不需要改任何代码**。

## 文件位置

```
dayflow/
├── index.html
├── app.js
└── data/
    └── quick-defaults.json   ← 在这里改
```

路径相对 `index.html`，改文件名或挪目录需要同步修改 `app.js` 里的
`QUICK_CONFIG_URL`（默认 `./data/quick-defaults.json`）。

## 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | 是 | 名称，最长 40 字，超长会自动截断 |
| `duration` | 否 | 预计时长（分钟），有效范围 5–720，缺省或非法按 30 处理 |
| `priority` | 否 | 优先级：`high`（高）/ `mid`（中）/ `low`（低），非法值按 `low` 处理 |

文件里有两个清单：

- `defaults`：常用内容默认清单（左栏「常用内容」卡片、新建面板里的快捷填充）
- `presets`：新建常用内容弹层里的快捷预设按钮（可选，缺省时用内置预设）

其他字段（`notes`、`version`、`updatedAt`）是给人看的注释，代码不校验。

## 生效范围（重要）

- **只对「默认值」生效**：常用内容保存后写进浏览器 localStorage，之后你在界面上的
  增删都存在本地，**改文件不会覆盖你已有的清单**（防止误伤自己加的内容）。
- 想让修改后的文件重新生效：打开「管理」→ 点底部「**恢复默认清单**」→ 再点一次确认。
  该入口会重新读取本文件并替换当前清单。
- 全新用户（或清空过浏览器数据）第一次打开时，直接展示本文件的内容。

## 加载与回退机制

1. 页面启动时，`app.js` 通过 `fetch('./data/quick-defaults.json')` 读取（带 3 秒超时、
   `no-cache`，保存刷新即生效，不受缓存干扰）。
2. 读取成功后逐条校验：非法项跳过或纠正，重名去重，最多保留 24 条（`presets` 12 条），
   问题会以 `[DayFlow]` 前缀输出到浏览器控制台。
3. **回退链**：文件缺失 / HTTP 失败 / JSON 语法错误 / `defaults` 为空或格式不对 →
   使用 `app.js` 内置的兜底清单 `QUICK_FALLBACK`（3 条），功能完全可用，仅控制台提示。
   界面上不会报错、不会白屏。

## 常见问题

- **双击 index.html 打开（file://）读不到文件？** 是的，浏览器安全策略禁止 `file://`
  下的 fetch。此时自动走内置兜底清单。请用本地服务（`python3 -m http.server`）或
  GitHub Pages 访问。
- **改了没反应？** 确认你是「新用户」或已通过「管理 → 恢复默认清单」应用；另外确认
  JSON 没有语法错误（多逗号、漏引号都会导致整份文件被跳过，控制台有提示）。
- **验证方法**：打开页面 → F12 → Console，无 `[DayFlow]` 告警即表示文件读取成功。
