# 常用内容默认数据配置

本目录下的 `quick-defaults.json` 是 DayFlow「常用内容」默认清单的**唯一数据来源**。
直接用任意文本编辑器打开修改、保存、刷新页面即可生效，**不需要改任何代码**。

## 文件位置

```
dayflow/
├── index.html
├── app.js
└── data/
    └── quick-defaults.json   ← 在这里改
```

路径相对 `index.html`，改文件名或挪目录需要同步修改 `app.js` 里的
`QUICK_CONFIG_URL`（默认 `./data/quick-defaults.json`）。

## 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | 是 | 名称，最长 40 字，超长会自动截断 |
| `duration` | 否 | 预计时长（分钟），有效范围 5–720，缺省或非法按 30 处理 |
| `priority` | 否 | 优先级：`high`（高）/ `mid`（中）/ `low`（低），非法值按 `low` 处理 |

文件里有两个清单：

- `defaults`：常用内容默认清单（左栏「常用内容」卡片、新建面板里的快捷填充）
- `presets`：新建常用内容弹层里的快捷预设按钮（可选，缺省时用内置预设）

其他字段（`notes`、`version`、`updatedAt`）是给人看的注释，代码不校验。

## 生效范围（重要）

改完文件保存，**刷新页面即可生效**，不需要点任何按钮。

判断规则很简单——看「当前清单是否等于上次同步进来的那份默认清单」：

| 你的情况 | 改文件后 |
|---|---|
| 从没用过 / 没在界面上增删过常用内容 | ✅ 刷新即整体替换为新内容（切回页面时也会自动同步，不用手动刷新） |
| 自己加过、改过、删过条目 | ⛔ 保留你的清单不动，避免误伤；想用新文件 → 「管理 → 恢复默认清单」点两次 |
| 清空过浏览器数据（等同于新用户） | ✅ 直接使用文件内容 |

同步成功后右侧会弹一条「常用内容已同步为配置文件的最新内容（N 条）」提示；
内容没变化时不会有任何提示。

想验证当前是否处于「未改动」状态：打开控制台执行
`JSON.parse(localStorage.getItem('dayflow.v1')).quickBase`——有值就说明上次是同步来的。

## 加载与回退机制

1. 页面启动时，`app.js` 通过 `fetch('./data/quick-defaults.json')` 读取（带 3 秒超时、
   `no-cache`，保存刷新即生效，不受缓存干扰）。
2. 切走再切回页面（或切换窗口）时会自动重读一次，所以你在编辑器里存盘后直接切回浏览器
   就能看到变化，连刷新都省了。
3. 读取成功后逐条校验：非法项跳过或纠正，重名去重（保留第一条），最多保留 24 条
   （`presets` 12 条），问题会以 `[DayFlow]` 前缀输出到浏览器控制台。
4. **回退链**：文件缺失 / HTTP 失败 / JSON 语法错误 / `defaults` 为空或格式不对 →
   保留当前清单不覆盖，页面正常可用，仅控制台提示；若此时还没有任何清单（首次打开），
   则使用 `app.js` 内置兜底清单 `QUICK_FALLBACK`（3 条）。界面上不会报错、不会白屏。

## 常见问题

- **双击 index.html 打开（file://）读不到文件？** 是的，浏览器安全策略禁止 `file://`
  下的 fetch。此时自动走内置兜底清单。请用本地服务（`python3 -m http.server`）或
  GitHub Pages 访问。
- **改了没反应？** 三种可能：①你在界面上改过常用内容，此时为了不误伤，文件不会覆盖你的清单
  →「管理 → 恢复默认清单」点两次；②JSON 有语法错误，整份文件被跳过（控制台有提示）；
  ③线上 GitHub Pages 有缓存，硬刷新或等半分钟。
- **想改完完全覆盖一次？** 直接点「管理 → 恢复默认清单」，它会重新读文件并整体替换。
- **验证方法**：打开页面 → F12 → Console，无 `[DayFlow]` 告警即表示文件读取成功。
