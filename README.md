# DayFlow · 日常时间安排

按时间线安排一天的轻量待办应用。纯静态页面，无需构建、无依赖，数据全部保存在浏览器本地。

## 功能

- 自定义卡片：标题、描述、预计时长、优先级
- 时间段选择器：起止时间输入 + 可视化时间标尺
- 常用内容一键填充
- 全部 / 未完成 / 已完成 筛选
- 时间线视图 ⇄ 列表视图切换，含「现在」时间指示线
- 响应式：桌面双栏、手机单栏 + 悬浮新建按钮
- localStorage 持久化，可添加到手机主屏幕

## 本地运行

```bash
python3 -m http.server 8791
# 打开 http://127.0.0.1:8791
```

直接双击 `index.html` 也能用，但 `manifest.json` 在 `file://` 下不生效。

## 部署到 GitHub Pages

1. 新建仓库并推送本目录（见根目录提交历史）
2. 仓库 **Settings → Pages → Source** 选 `main` 分支、`/ (root)`，保存
3. 等待约 1 分钟，访问 `https://<用户名>.github.io/<仓库名>/`

所有资源均为相对路径，部署在子路径下无需改动。

## 自定义常用内容默认清单

常用内容的默认数据集中在 `data/quick-defaults.json`，直接编辑保存、刷新页面即可，
无需改代码。字段格式、生效范围与回退机制见 [`data/README.md`](data/README.md)。
